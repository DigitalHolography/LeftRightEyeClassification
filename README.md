# LeftRightEyeClassification

[![Hugging Face](https://img.shields.io/badge/Hugging_Face-YOLO__EyeSide-teal?style=plastic&logo=huggingface&logoColor=yellow)](https://huggingface.co/DigitalHolography/YOLO_EyeSide)

An **eye laterality** (left / right) classification pipeline for mean retinal Doppler holography moment-0 images generated by [HoloDoppler](https://github.com/DigitalHolography/HoloDoppler).

## Repository structure

```
├── notebooks/   # Training, evaluation and experiment notebooks
├── src/libs/    # Helper functions used by the notebooks
├── dataset/     # Datasets
└── other/       # Extra files (articles, information, weights)
```

## Installation

The project uses [uv](https://docs.astral.sh/uv/) and requires Python ≥ 3.14.

```bash
uv sync
```

## Dataset

Dataset utilities live in [`src/libs/dataset.py`](src/libs/dataset.py) and are used throughout the project.

1. Get a CSV listing the dataset images.
2. Download the images locally with `download_images`.
3. Generate the required datasets from that local folder of anonymised images.

> [!IMPORTANT]
> - Each subject must have **at most one image per side**.
> - A subject must never appear in more than one split (train / valid / test).

## Notebooks

| Notebook | Purpose |
| --- | --- |
| [`kfold.ipynb`](notebooks/kfold.ipynb) | 5-fold cross-validation for model evaluation and hyperparameter selection |
| [`train.ipynb`](notebooks/train.ipynb) | Trains the final model on the full train set (100 images) and evaluates it on the test set (84 images) |
| [`benchmark.ipynb`](notebooks/benchmark.ipynb) | Learning curve and other experiments for evaluating the model |
| [`evaluate.ipynb`](notebooks/evaluate.ipynb) | Helpers to inspect model performance (accuracy, confusion matrix, …) |

## Training configuration

All parameters used to train the final YOLO model are stored in [`other/information/model_args.yaml`](other/information/model_args.yaml).
